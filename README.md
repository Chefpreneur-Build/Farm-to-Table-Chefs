# Farm to Table Chefs

A responsive homepage for Chef Christian, built with Vite, HTML, CSS, and JavaScript.

## Development

```sh
npm ci --cache /tmp/chef-npm-cache
npm run dev -- --port 3000
```

## Production

```sh
npm run build
npm run preview
```

Publish the generated `dist/` directory with any static web host.

Includes responsive navigation, seasonal service tabs, a sample-menu dialog, testimonial navigation, scroll reveals, reduced-motion support, and button sheen effects.

## Before launch

- Replace substitute Unsplash photographs, typographic logos, and decorative artwork with the original brand assets to reproduce the supplied reference precisely. Images and Google Fonts require Internet access in the visitor’s browser.
- Connect the reservation form to a booking or email service. Currently it validates fields and explicitly states that no booking was sent.
- Replace generic social platform links with Chef Christian’s verified profiles.
- Confirm service details, pricing, testimonial permission, and sample menu copy. Only the first slide is a customer testimonial supplied in the design; other slides contain brand statements.
